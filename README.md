## 🌌 Story Campaign Overview
Rogue AI sentinels have overrun the grid mainframe. As a cyber operator, infiltrate the sectors, adapt your loadout, utilize tactical abilities, and clean the security perimeters.

### Features
* **Vanishing-Edge 3D Engine**: Built completely on Three.js WebGL graphics.
* **Dual Weapon Loadout**: Swap between SMGs, precision energy railguns, plasma shotguns, and bolt-action snipers.
* **Character Ability Suite**: Activate healing auras, kinetic shields, invisibility cloaks, or sound wave strikes.
* **Dual Input Interfaces**: Custom PC keyboard/mouse control schemes and mobile virtual combat clusters.
* **Integrated Developer Sandbox**: Access hidden panels to customize the level structures in real-time.

## 🕹️ Control Interface

### 💻 PC Controls
* **`W` `A` `S` `D`**: Movement
* **`Shift`**: Walk silently (bypass movement scanners)
* **`Ctrl`**: Crouch
* **`Space`**: Jump
* **`Left-Click`**: Fire weapon
* **`Right-Click`**: Scope zoom (Sniper AWM / Pulse)
* **`R`**: Reload clip
* **`1` / `2`**: Swap primary / secondary slots
* **`3`**: Melee strike
* **`4`**: Throw frag grenade
* **`5`**: Activate selected character ability

### 📱 Touchscreen (Mobile/Tablet)
* **Left Virtual Joystick**: Move character.
* **Action Buttons Cluster**: Circular layout containing fire, jump, scope, reload, crouch, swap, grenade, melee, and ability triggers.
